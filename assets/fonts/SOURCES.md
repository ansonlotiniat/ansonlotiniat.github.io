## Goodnotes handwriting

- Typeface source: [LXGW WenKai TC](https://github.com/lxgw/LxgwWenKaiTC), version `1.522`.
- Original release asset: `LXGWWenKaiTC-Regular.ttf`, downloaded from the official GitHub release.
- Original SHA-256: `b1a0795862c1415bf3f393ea50b2a4ea6275012cf5bad3f94feeb1222f555731`.
- Licence: SIL Open Font License 1.1; retained in `LXGW-WenKai-TC-OFL.txt`.
- Web asset: `anson-hand-notes.woff`, subset from the release font with FontTools `4.62.1` using the characters present in `main.js`, then served under the non-reserved CSS family name `Anson Hand Notes`.
- Web asset SHA-256: `e45151e25bb6c5c155ad9228b6f74ca47ebcc17ee8552febedba5edc3937485c`.
- The subset is for web delivery only and is not presented as an installable desktop font.
