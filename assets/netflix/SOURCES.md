# Netflix visual source

`wordmark.png` is the current red Netflix wordmark from Netflix's official
[Company Assets](https://about.netflix.com/en/company-assets) page. The source file is
[`Netflix-Brand-Logo.png`](https://images.ctfassets.net/4cd45et68cgf/7LrExJ6PAj6MSIPkDyCO86/542b1dfabbf3959908f69be546879952/Netflix-Brand-Logo.png).

The transparent canvas was cropped with macOS `sips`; the mark itself was not recoloured,
stretched, rotated, or redrawn. It is used only to identify the represented Netflix interface.
Netflix retains all rights in its name and marks. No digest was generated for this update.

## Personal-list title art

The four title backdrops and title logos under `titles/` come from the public Netflix
title pages linked below. The JPEG files are Netflix's official 992 x 558 responsive
backdrops. The PNG files are the corresponding transparent title art. They are stored
locally so the portfolio does not depend on signed-in Netflix state or a changing CDN
request at runtime.

region. No Netflix account, watch history, profile, or signed-in session was accessed.
