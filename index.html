01 / METHOD

我不從畫面開始。 I do not start with screens.

畫面只是最後被看見的一層。前面還有情境、角色、任務、權限、資料和語氣。 The screen is only the final visible layer. Before it come context, roles, tasks, permissions, data, and tone.

  1. 01

    觀察情境Observe context

    誰在使用？事情在哪裡發生？Who is using it? Where does the work happen?

    WHO / WHERE
  2. 02

    整理流程Shape the flow

    資訊在哪裡斷開？哪一步其實可以消失？Where does information break? Which step can disappear?

    ORDER / STATE
  3. 03

    清楚交付Deliver clearly

    使用者能不能不用猜，就知道下一步？Can the user see the next step without guessing?

    WHAT NEXT?

BOOK / EDITOR / 2025

《澳門日記—回歸故事集》

我以「羅天逸」列於編輯名單。編輯時要兼顧文字準確，也要保留每位說話者本來的聲音。 I am credited as “羅天逸” in the editorial team. The work required accuracy while retaining each speaker’s own voice.

We talk about exams,

about the future like it’s a city

neither of us has visited,

but somehow we keep pointing

in the same direction.
